SECTION A: CONCEPT APPLICATION

Question 1:
Using NumPy vectorisation is much better here than a Python for-loop because a regular loop processes all 50,000 distances one by one inside the Python interpreter. On every single iteration, Python has to check data types and grow the output list in memory, which gets slow very quickly. NumPy avoids this by running the calculation directly in pre-compiled C code over a contiguous block of memory.

When we multiply the entire array by a single scalar rate like Rs 5 per km, NumPy broadcasting lets that single number act as if it were an array of 50,000 fives without actually copying it 50,000 times in memory. That keeps memory usage low and lets us write the whole calculation in one line.

That said, a Python loop is still needed when each step depends on the result of the previous step. For example, if the surge fee for order $i$ depends on how many drivers are still free after order $i-1$ was assigned, you cannot compute every order independently at the same time and have to loop through them sequentially.


Question 2:
Using groupby() with agg() is far better than looping over each restaurant because filtering a DataFrame inside a loop forces Pandas to scan the entire table repeatedly, once for every unique restaurant. That creates unnecessary temporary copies and slows down as the restaurant count grows. In contrast, groupby() groups all rows in a single pass using an internal hash table and computes all the aggregations together.

The method chain to get all three metrics in one go would look like this:

result = df.groupby("restaurant_name").agg(
    avg_order_value=("order_value", "mean"),
    avg_delivery_time=("delivery_time_mins", "mean"),
    avg_rating=("rating", "mean")
)

After running this operation, the index of the resulting DataFrame holds the unique restaurant names, so each row represents one restaurant.


Question 3:
For total orders per month over a year, a line chart is the best fit because the data is a time series and connecting the monthly points makes seasonal trends and growth easy to spot. For the proportion of orders by cuisine type, a pie chart works well since there are only four discrete categories and we specifically want to show each cuisine's share of the whole. For the distribution of delivery times, a histogram is the right choice because delivery time is continuous numeric data, and binning it shows the spread, central peak, and any skew or long tail.

To place all three charts side by side in a single figure, I would configure subplots as:
fig, axes = plt.subplots(1, 3, figsize=(18, 5))
This creates one row with three columns, and each chart can be plotted on axes[0], axes[1], and axes[2].

A shared x-axis (sharex=True) would not make sense here because the three plots have completely unrelated x-axes: months of the year, cuisine proportions (which do not even use a standard x-axis in a pie chart), and delivery times in minutes. Forcing them to share one x-axis would break the scaling and make the charts unreadable.


Question 4:
To mark the peak day automatically, I would first find its index using max_idx = np.argmax(orders), then grab the corresponding day (max_day = days[max_idx]) and order count (max_vol = orders[max_idx]). Then I would pass those values directly into plt.annotate() with a formatted string showing the day and volume.

Two important parameters to pass are:
1. xy=(max_day, max_vol): This sets the exact data point on the line chart that the arrow points to.
2. xytext=(max_day + 5, max_vol - 40): This controls where the text label sits on the chart so it stays readable and does not sit directly on top of the line.
We would also pass arrowprops (for example, arrowprops=dict(arrowstyle="->", color="red")) to draw and style the arrow connecting the text label to the peak.


Question 5:
For this dataset, I would recommend sns.boxplot() over sns.violinplot(). First, customer ratings are on a discrete 1 to 5 scale. A violin plot uses kernel density estimation to draw smooth curves, which creates artificial waves between whole numbers and can even extend past 1 and 5, making discrete ratings look continuous. Second, with 10,000 rows and 3 categories, the manager specifically wants to spot extreme outliers. A boxplot handles large row counts cleanly by summarizing the median and quartiles while plotting individual outlier points beyond $1.5 \times \text{IQR}$ right on the chart.

A violin plot would be the better option if we were looking at a truly continuous column like delivery time or order value, especially if we suspected the data had two separate peaks (multimodality), such as fast off-peak deliveries and slow peak-hour deliveries, which a boxplot cannot show.


Question 6:
To check for multicollinearity, I would compute the Pearson correlation matrix with corr = df.corr(numeric_only=True) and pass it into sns.heatmap(corr, annot=True, cmap="coolwarm", vmin=-1, vmax=1).

The colour scale represents both the direction and strength of the linear relationship between each pair of variables, ranging from -1 to +1. With a diverging palette like coolwarm, strong positive correlations appear dark red, strong negative correlations appear dark blue, and values near zero appear light or neutral. To read a specific cell, you look at the intersection of a row feature and a column feature; the number printed inside the cell is their Pearson correlation coefficient $r$.

Conventionally, a correlation magnitude of $|r| \ge 0.8$ (or sometimes $|r| \ge 0.7$) is used to flag a multicollinearity risk. At $|r| = 0.8$, the two variables share $R^2 = 0.64$ (64%) of their variance, which is high enough to inflate the variance of regression coefficients and make the model's feature weights unstable.

Task 2: Restaurant Performance Analyser (section_b_task2.py)

import numpy as np
import pandas as pd

np.random.seed(42)

n_rows = 50
restaurants = [
    "Spice Route",
    "Urban Tandoor",
    "Wok Express",
    "Burger Barn",
    "Royal Biryani",
]
cities = ["Vadodara", "Ahmedabad", "Surat"]
cuisines = ["Indian", "Chinese", "Fast Food"]

rest_col = np.random.choice(restaurants, size=n_rows)
ratings = []
delivery_times = []

for r in rest_col:
    if r in ["Spice Route", "Royal Biryani"]:
        ratings.append(np.round(np.random.uniform(4.1, 5.0), 1))
        delivery_times.append(np.round(np.random.uniform(20, 34), 1))
    else:
        ratings.append(np.round(np.random.uniform(2.5, 4.5), 1))
        delivery_times.append(np.round(np.random.uniform(28, 50), 1))

df = pd.DataFrame({
    "restaurant_name": rest_col,
    "city": np.random.choice(cities, size=n_rows),
    "order_value": np.round(np.random.uniform(150, 900, size=n_rows), 2),
    "delivery_time_mins": delivery_times,
    "rating": ratings,
    "cuisine_type": np.random.choice(cuisines, size=n_rows),
})

grouped = df.groupby("restaurant_name").agg(
    mean_order_value=("order_value", "mean"),
    mean_delivery_time=("delivery_time_mins", "mean"),
    mean_rating=("rating", "mean"),
)

filtered = grouped[
    (grouped["mean_rating"] > 4.0) & (grouped["mean_delivery_time"] < 35)
]

final_result = (
    filtered.sort_values(by="mean_order_value", ascending=False)
    .reset_index()
    .round(2)
)

print(final_result.to_string(index=False))


Task 3: Monthly Order Trend Dashboard (section_b_task3.py)

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun",
          "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"]
total_orders = np.random.randint(1000, 5001, size=12)
avg_order_values = np.random.uniform(200, 400, size=12)
monthly_revenue = total_orders * avg_order_values
monthly_avg_delivery = np.random.normal(loc=28, scale=4, size=12)

sim_mean = np.mean(monthly_avg_delivery)
sim_std = np.std(monthly_avg_delivery)
simulated_delivery_times = np.random.normal(loc=sim_mean, scale=sim_std, size=500)

fig, axes = plt.subplots(1, 3, figsize=(18, 5))
fig.suptitle("Food Delivery Monthly Performance Dashboard", fontsize=15)

axes[0].plot(months, total_orders, marker="o", color="#1f77b4", linewidth=2)
for i, val in enumerate(total_orders):
    axes[0].annotate(
        f"{val}",
        (months[i], val),
        textcoords="offset points",
        xytext=(0, 8),
        ha="center",
        fontsize=8,
    )
axes[0].set_title("Total Orders per Month")
axes[0].set_xlabel("Month")
axes[0].set_ylabel("Total Orders")
axes[0].set_ylim(0, max(total_orders) * 1.15)
axes[0].grid(True, linestyle="--", alpha=0.4)

threshold = 800000
bar_colors = ["green" if rev > threshold else "red" for rev in monthly_revenue]
axes[1].bar(months, monthly_revenue / 1e5, color=bar_colors)
axes[1].axhline(threshold / 1e5, color="black", linestyle="--", label="Rs 8,00,000")
axes[1].set_title("Monthly Revenue (Rs Lakhs)")
axes[1].set_xlabel("Month")
axes[1].set_ylabel("Revenue (Lakhs)")
axes[1].legend()

sample_mean = np.mean(simulated_delivery_times)
axes[2].hist(simulated_delivery_times, bins=15, color="#4c72b0", edgecolor="black")
axes[2].axvline(sample_mean, color="red", linestyle="--", label="Mean")
axes[2].set_title("Delivery Time Distribution")
axes[2].set_xlabel("Delivery Time (mins)")
axes[2].set_ylabel("Frequency")
axes[2].legend()

plt.tight_layout(rect=[0, 0, 1, 0.94])
plt.savefig("food_delivery_dashboard.png", dpi=150)

Task 4: Full EDA Pipeline - Food Delivery Insights (section_b_task4.py)

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

np.random.seed(7)
n_rows = 200

df = pd.DataFrame({
    "order_value": np.random.uniform(100, 800, size=n_rows),
    "distance_km": np.random.uniform(1, 20, size=n_rows),
    "delivery_time_mins": np.clip(np.random.normal(loc=30, scale=8, size=n_rows), 5, None),
    "rating": np.random.uniform(1.0, 5.0, size=n_rows),
    "discount_pct": np.random.uniform(0, 30, size=n_rows),
})

n_nulls = int(0.05 * n_rows)
for col in ["delivery_time_mins", "rating"]:
    null_indices = np.random.choice(df.index, size=n_nulls, replace=False)
    df.loc[null_indices, col] = np.nan

df["delivery_time_mins"] = df["delivery_time_mins"].fillna(df["delivery_time_mins"].median())
df["rating"] = df["rating"].fillna(df["rating"].median())

df["delivery_speed_kmph"] = df["distance_km"] / (df["delivery_time_mins"] / 60.0)
df["speed_band"] = pd.qcut(
    df["delivery_speed_kmph"],
    q=3,
    labels=["Slow", "Normal", "Fast"],
)

print(df.head())
print("\nSpeed Band Counts:")
print(df["speed_band"].value_counts())

numeric_cols = df.select_dtypes(include=[np.number]).columns
corr_matrix = df[numeric_cols].corr(method="pearson")

plt.figure(figsize=(9, 7))
sns.heatmap(corr_matrix, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1)
plt.title("Pearson Correlation Matrix")
plt.tight_layout()
plt.savefig("correlation_heatmap.png", dpi=150)
plt.close()

pairplot_cols = ["order_value", "distance_km", "delivery_time_mins", "rating", "speed_band"]
g = sns.pairplot(df[pairplot_cols], hue="speed_band", palette="Set2")
g.fig.suptitle("Food Delivery Pairplot by Speed Band", y=1.02)
plt.savefig("pairplot.png", dpi=150, bbox_inches="tight")
plt.close()


SECTION C: MINI CAPSTONE PROJECT (section_c_capstone.py)

import matplotlib
matplotlib.use("Agg")

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns


def load_and_clean_data(n_rows=250, seed=42):
    np.random.seed(seed)
    restaurants = [
        "Spice Route",
        "Urban Tandoor",
        "Wok Express",
        "Burger Barn",
        "Royal Biryani",
        "Pasta Palace",
    ]
    cuisines = ["Indian", "Chinese", "Fast Food", "Italian"]

    df = pd.DataFrame({
        "restaurant_name": np.random.choice(restaurants, size=n_rows),
        "cuisine_type": np.random.choice(cuisines, size=n_rows),
        "order_value": np.round(np.random.uniform(120, 950, size=n_rows), 2),
        "distance_km": np.round(np.random.uniform(1.0, 18.0, size=n_rows), 2),
        "delivery_time_mins": np.round(np.clip(np.random.normal(32, 7, size=n_rows), 10, None), 1),
        "rating": np.round(np.random.uniform(2.0, 5.0, size=n_rows), 1),
        "discount_pct": np.round(np.random.uniform(0, 25, size=n_rows), 1),
    })

    for col in ["delivery_time_mins", "rating"]:
        idx = np.random.choice(df.index, size=int(0.04 * n_rows), replace=False)
        df.loc[idx, col] = np.nan

    numeric_cols = df.select_dtypes(include=[np.number]).columns
    for col in numeric_cols:
        if df[col].isnull().any():
            df[col] = df[col].fillna(df[col].median())

    return df


def summary_statistics(df):
    print("\nSummary Statistics:")
    numeric_cols = df.select_dtypes(include=[np.number]).columns
    print(f"{'Column':<20} {'Mean':>10} {'Median':>10} {'Std':>10} {'Min':>10} {'Max':>10}")
    for col in numeric_cols:
        arr = df[col].to_numpy()
        print(
            f"{col:<20} {np.mean(arr):>10.2f} {np.median(arr):>10.2f} "
            f"{np.std(arr):>10.2f} {np.min(arr):>10.2f} {np.max(arr):>10.2f}"
        )


def distribution_analysis(df):
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))
    fig.suptitle("Order Value and Delivery Time Distributions")

    axes[0].hist(df["order_value"], bins=20, color="#2a9d8f", edgecolor="black")
    axes[0].set_title("Order Value")
    axes[0].set_xlabel("Order Value (Rs)")
    axes[0].set_ylabel("Count")

    axes[1].hist(df["delivery_time_mins"], bins=20, color="#e76f51", edgecolor="black")
    axes[1].set_title("Delivery Time")
    axes[1].set_xlabel("Delivery Time (mins)")
    axes[1].set_ylabel("Count")

    plt.tight_layout(rect=[0, 0, 1, 0.93])
    plt.savefig("capstone_distribution_analysis.png", dpi=150)
    plt.close()
    print("\nSaved capstone_distribution_analysis.png")


def correlation_heatmap(df):
    corr = df.select_dtypes(include=[np.number]).corr(method="pearson")
    plt.figure(figsize=(8, 6))
    sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1)
    plt.title("Correlation Heatmap")
    plt.tight_layout()
    plt.savefig("capstone_correlation_heatmap.png", dpi=150)
    plt.close()
    print("\nSaved capstone_correlation_heatmap.png")


def restaurant_performance(df):
    report = (
        df.groupby("restaurant_name")
        .agg(
            total_orders=("order_value", "count"),
            avg_order_value=("order_value", "mean"),
            avg_delivery_time=("delivery_time_mins", "mean"),
            avg_rating=("rating", "mean"),
        )
        .sort_values(by="avg_rating", ascending=False)
        .round(2)
    )
    print("\nRestaurant Performance Report:")
    print(report.to_string())


def exit_summary(df):
    print("\nFINAL SUMMARY REPORT")
    print("-" * 40)

    top3 = (
        df.groupby("restaurant_name")["rating"]
        .mean()
        .sort_values(ascending=False)
        .head(3)
    )
    print("Top 3 Restaurants by Mean Rating:")
    for rank, (name, score) in enumerate(top3.items(), start=1):
        print(f"{rank}. {name}: {score:.2f}")

    corr = df.select_dtypes(include=[np.number]).corr(method="pearson").abs()
    np.fill_diagonal(corr.values, 0)
    max_pair = corr.stack().idxmax()
    actual_corr = df[max_pair[0]].corr(df[max_pair[1]])
    print(f"\nHighest Correlation Pair: {max_pair[0]} and {max_pair[1]} (r = {actual_corr:.4f})")

    dt_mean = np.mean(df["delivery_time_mins"])
    dt_std = np.std(df["delivery_time_mins"])
    print(f"Delivery Time -> Mean: {dt_mean:.2f} mins, Std Dev: {dt_std:.2f} mins")


def main():
    df = load_and_clean_data(n_rows=250)

    while True:
        print("\nFood Delivery Analytics Menu")
        print("1. Summary Statistics")
        print("2. Distribution Analysis")
        print("3. Correlation Heatmap")
        print("4. Restaurant Performance Report")
        print("5. Exit")

        choice = input("Enter your choice (1-5): ").strip()

        if choice == "1":
            summary_statistics(df)
        elif choice == "2":
            distribution_analysis(df)
        elif choice == "3":
            correlation_heatmap(df)
        elif choice == "4":
            restaurant_performance(df)
        elif choice == "5":
            exit_summary(df)
            break
        else:
            print("Invalid option, please try again.")


if __name__ == "__main__":
    main()

import numpy as np

4. Explanation of Changes:
When I ran the AI's code, df.corr() threw a ValueError in Pandas 2.x because the cuisine_type column contains strings, so I added numeric_only=True to fix it. I also added plt.close() after saving the pairplot and created a fresh plt.figure() for the heatmap so the two charts would not overlap. Finally, I added dpi=150, bbox_inches="tight", and plt.tight_layout() so the saved PNGs come out sharp without cutting off any labels.
