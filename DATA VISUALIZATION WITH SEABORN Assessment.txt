SCENARIO 1: NumPy Vectorisation vs. Python Loops
------------------------------------------------
- Why vectorisation is superior:
  A Python for-loop iterates through 50,000 elements one by one, incurring
  interpreter overhead, dynamic type-checking, and memory reallocation (via
  list.append()) on every iteration. NumPy vectorisation delegates the entire
  arithmetic operation to pre-compiled, contiguous C loops that execute directly
  on typed memory buffers, making it orders of magnitude faster and more
  memory-efficient.

- Role of broadcasting:
  When multiplying a 1D array of 50,000 distances by a single scalar (e.g., Rs 5),
  broadcasting virtually stretches the scalar to match the shape (50000,) without
  physically copying the scalar 50,000 times in memory, allowing element-wise
  computation in a single expression.

- When a Python loop is still necessary:
  When each element's calculation depends sequentially on the result of the
  previous element (e.g., a stateful running simulation or dynamic pricing where
  order $i$'s surge fee depends on the cumulative driver availability updated by
  order $i-1$), or when invoking external non-vectorisable functions such as API
  calls or complex nested string/JSON parsing.


SCENARIO 2: Pandas groupby() + agg() vs. Manual Loops
-----------------------------------------------------
- Why groupby().agg() is superior:
  Filtering a DataFrame inside a for-loop scans the entire dataset repeatedly
  (once per unique restaurant), creating temporary DataFrame copies and scaling
  poorly as the number of restaurants grows. groupby() uses a single-pass
  hash-based split-apply-combine engine implemented in Cython/C, computing all
  aggregations simultaneously in one pass.

- Method chain:
  summary = df.groupby("restaurant_name").agg(
      avg_order_value=("order_value", "mean"),
      avg_delivery_time=("delivery_time_mins", "mean"),
      avg_rating=("rating", "mean"),
  )

- Resulting index:
  After groupby("restaurant_name"), the resulting DataFrame's index represents
  the unique values of restaurant_name (each row corresponds to one distinct
  restaurant).


SCENARIO 3: Choosing Matplotlib Charts & plt.subplots()
-------------------------------------------------------
- Chart choices and justifications:
  (a) Total orders per month over a year -> Line Chart (ax.plot):
      Best for continuous time-series data to highlight trends, seasonality,
      and month-over-month trajectory.
  (b) Proportion of orders by cuisine type -> Pie Chart (ax.pie) or Horizontal
      Bar Chart (ax.barh):
      A pie chart directly communicates part-to-whole percentages across 4
      discrete categories (Fast Food, Indian, Chinese, Desserts).
  (c) Distribution of delivery times -> Histogram (ax.hist):
      Groups continuous numerical values into bins to reveal spread, central
      tendency, skewness, and outliers.

- Configuring plt.subplots():
  Use fig, axes = plt.subplots(1, 3, figsize=(18, 5)) to create a 1-row,
  3-column figure side by side, accessing each subplot via axes[0], axes[1],
  and axes[2].

- Shared x-axis (sharex=True):
  Not appropriate. Each chart has a completely different x-axis domain: months
  (time), categorical proportions (no standard x-axis for a pie chart), and
  delivery time in minutes (continuous numeric). Sharing an x-axis would distort
  scales and break readability.


SCENARIO 4: Programmatic Peak Annotation with plt.annotate()
------------------------------------------------------------
- Programmatic identification:
  Find the index of the maximum order volume using max_idx = np.argmax(orders),
  then retrieve max_day = days[max_idx] and max_vol = orders[max_idx]. Pass
  these coordinates directly into plt.annotate().

- Key parameters:
  1. xy=(max_day, max_vol): Sets the exact (x, y) data coordinate of the peak
     that the arrow tip points to.
  2. xytext=(max_day + 5, max_vol - 50): Sets the (x, y) coordinate where the
     text label (e.g., f"Day {max_day}: {max_vol} orders") is positioned so it
     does not overlap the line.
  3. arrowprops=dict(arrowstyle="->", color="red", lw=1.5): Controls the
     presence, style, colour, and thickness of the arrow connecting xytext to xy.


SCENARIO 5: sns.boxplot() vs. sns.violinplot()
----------------------------------------------
- Recommendation:
  sns.boxplot() is better suited for this task.

- Two data-specific reasons:
  1. Discrete 1-5 rating scale: A violin plot relies on Kernel Density
     Estimation (KDE), which smooths data into continuous curves. On a discrete
     1-5 integer scale, KDE creates artificial "bulges" and extends tails past
     1 and 5, misrepresenting the discrete nature of the ratings.
  2. Explicit outlier detection across 10,000 rows: The manager specifically
     wants to see if any of the 3 categories produces more extreme outliers. A
     boxplot explicitly plots individual outlier points beyond $1.5 \times \text{IQR}$
     while cleanly summarizing medians and quartiles without visual clutter
     across 10,000 rows.

- When sns.violinplot() is preferable:
  When analysing a continuous variable (such as delivery_time_mins or
  order_value) where detecting multimodality (e.g., two distinct delivery-time
  peaks for peak vs. off-peak hours) matters -- something a boxplot hides
  completely.


SCENARIO 6: Seaborn Correlation Heatmap & Multicollinearity
-----------------------------------------------------------
- Generation:
  Compute the Pearson correlation matrix with corr = df.corr(numeric_only=True)
  and plot it using sns.heatmap(corr, annot=True, cmap="coolwarm", vmin=-1, vmax=1).

- Colour scale:
  Represents the strength and direction of the linear relationship ($r$ from -1.0
  to +1.0). A diverging palette maps strong positive correlations to one extreme
  (e.g., dark red), strong negative correlations to the other (e.g., dark blue),
  and near-zero correlation to a neutral centre (white/grey).

- Reading a cell:
  Each cell at row $i$, column $j$ displays the Pearson correlation coefficient
  $r$ between feature $i$ and feature $j$ (e.g., distance_km vs.
  delivery_time_mins might read 0.84, indicating a strong positive linear
  relationship).

- Multicollinearity threshold:
  Conventionally $|r| \ge 0.8$ (sometimes $|r| \ge 0.7$). Above this threshold,
  two predictors share a large proportion of variance ($R^2 \ge 0.64$), which
  inflates the variance of regression coefficients (high VIF), makes feature
  weights unstable, and degrades model interpretability.

import numpy as np

# 1. Generate 1D array of 25 random delivery distances (1.0 to 15.0 km), seed=42
np.random.seed(42)
distances = np.random.uniform(1.0, 15.0, size=25)

# 2. Vectorised delivery fee calculation: fee = 20 + 5 * distance
fees = 20 + 5 * distances

# 3. Boolean indexing for orders where fee > Rs 60
high_fee_mask = fees > 60
qualifying_distances = distances[high_fee_mask]
qualifying_fees = fees[high_fee_mask]

print("=== Orders with Delivery Fee > Rs 60 ===")
for idx, (dist, fee) in enumerate(zip(qualifying_distances, qualifying_fees), start=1):
    print(f"Order {idx:2d}: Distance = {dist:5.2f} km | Fee = Rs {fee:6.2f}")

# 4. Statistical summary of complete fee array
print("\n=== Complete Fee Array Statistics ===")
print(f"Minimum Fee : Rs {np.min(fees):.2f}")
print(f"Maximum Fee : Rs {np.max(fees):.2f}")
print(f"Mean Fee    : Rs {np.mean(fees):.2f}")
print(f"Std Dev Fee : Rs {np.std(fees):.2f}")


=== TASK 2: Restaurant Performance Analyser (section_b_task2.py) ===

import numpy as np
import pandas as pd

np.random.seed(42)

# 1. Construct a 50-row DataFrame (>= 40 rows)
n_rows = 50
restaurants = [
    "Spice Route",
    "Urban Tandoor",
    "Wok Express",
    "Burger Barn",
    "Royal Biryani",
]
cities = ["Vadodara", "Ahmedabad", "Surat"]
cuisines = ["Indian", "Chinese", "Fast Food"]

# Assign base profiles so realistic restaurants qualify for the filter
rest_col = np.random.choice(restaurants, size=n_rows)
ratings = []
delivery_times = []

for r in rest_col:
    if r in ["Spice Route", "Royal Biryani"]:
        ratings.append(np.round(np.random.uniform(4.1, 5.0), 1))
        delivery_times.append(np.round(np.random.uniform(20, 34), 1))
    else:
        ratings.append(np.round(np.random.uniform(2.5, 4.5), 1))
        delivery_times.append(np.round(np.random.uniform(28, 50), 1))

df = pd.DataFrame({
    "restaurant_name": rest_col,
    "city": np.random.choice(cities, size=n_rows),
    "order_value": np.round(np.random.uniform(150, 900, size=n_rows), 2),
    "delivery_time_mins": delivery_times,
    "rating": ratings,
    "cuisine_type": np.random.choice(cuisines, size=n_rows),
})

# 2. Single method chain with groupby() and agg()
grouped = df.groupby("restaurant_name").agg(
    mean_order_value=("order_value", "mean"),
    mean_delivery_time=("delivery_time_mins", "mean"),
    mean_rating=("rating", "mean"),
)

# 3. Filter: mean rating > 4.0 and mean delivery time < 35 mins
filtered = grouped[
    (grouped["mean_rating"] > 4.0) & (grouped["mean_delivery_time"] < 35)
]

# 4. Sort by mean order value descending, reset index, and print
final_result = (
    filtered.sort_values(by="mean_order_value", ascending=False)
    .reset_index()
    .round(2)
)

print("=== Top Performing Restaurants (Rating > 4.0 & Delivery Time < 35 mins) ===")
print(final_result.to_string(index=False))

=== TASK 4: Full EDA Pipeline - Food Delivery Insights (section_b_task4.py) ===

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 1. Generate 200-row dataset using NumPy (seed=7)
np.random.seed(7)
n_rows = 200

df = pd.DataFrame({
    "order_value": np.random.uniform(100, 800, size=n_rows),
    "distance_km": np.random.uniform(1, 20, size=n_rows),
    "delivery_time_mins": np.clip(np.random.normal(loc=30, scale=8, size=n_rows), 5, None),
    "rating": np.random.uniform(1.0, 5.0, size=n_rows),
    "discount_pct": np.random.uniform(0, 30, size=n_rows),
})

# 2. Introduce 5% nulls in delivery_time_mins and rating using np.random.choice()
n_nulls = int(0.05 * n_rows)
for col in ["delivery_time_mins", "rating"]:
    null_indices = np.random.choice(df.index, size=n_nulls, replace=False)
    df.loc[null_indices, col] = np.nan

print("Null counts before imputation:")
print(df.isnull().sum())

# Fill nulls with respective column medians
df["delivery_time_mins"] = df["delivery_time_mins"].fillna(df["delivery_time_mins"].median())
df["rating"] = df["rating"].fillna(df["rating"].median())

print("\nNull counts after imputation:")
print(df.isnull().sum())

# 3. Derived column & speed_band classification using pd.qcut()
df["delivery_speed_kmph"] = df["distance_km"] / (df["delivery_time_mins"] / 60.0)
df["speed_band"] = pd.qcut(
    df["delivery_speed_kmph"],
    q=3,
    labels=["Slow", "Normal", "Fast"],
)

print("\nSpeed Band Distribution:")
print(df["speed_band"].value_counts())

# 4. Seaborn correlation heatmap (DPI >= 150)
numeric_cols = df.select_dtypes(include=[np.number]).columns
corr_matrix = df[numeric_cols].corr(method="pearson")

plt.figure(figsize=(9, 7))
sns.heatmap(corr_matrix, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1, linewidths=0.5)
plt.title("Pearson Correlation Matrix - Food Delivery Features")
plt.tight_layout()
plt.savefig("correlation_heatmap.png", dpi=150)
plt.close()
print("\nSaved: correlation_heatmap.png")

# 5. Seaborn pairplot coloured by speed_band (DPI >= 150)
pairplot_cols = ["order_value", "distance_km", "delivery_time_mins", "rating", "speed_band"]
g = sns.pairplot(df[pairplot_cols], hue="speed_band", palette="Set2", diag_kind="kde")
g.fig.suptitle("Food Delivery Feature Pairplot by Speed Band", y=1.02)
plt.savefig("pairplot.png", dpi=150, bbox_inches="tight")
plt.close()
print("Saved: pairplot.png")

import matplotlib
matplotlib.use("Agg")  # Non-interactive backend so charts are never displayed during menu loop

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns


def generate_and_clean_dataset(n_rows=250, seed=42):
    """Generate >= 200 rows with NumPy, introduce nulls, and impute all numeric nulls."""
    np.random.seed(seed)
    restaurants = [
        "Spice Route",
        "Urban Tandoor",
        "Wok Express",
        "Burger Barn",
        "Royal Biryani",
        "Pasta Palace",
    ]
    cuisines = ["Indian", "Chinese", "Fast Food", "Italian"]

    df = pd.DataFrame({
        "restaurant_name": np.random.choice(restaurants, size=n_rows),
        "cuisine_type": np.random.choice(cuisines, size=n_rows),
        "order_value": np.round(np.random.uniform(120, 950, size=n_rows), 2),
        "distance_km": np.round(np.random.uniform(1.0, 18.0, size=n_rows), 2),
        "delivery_time_mins": np.round(np.clip(np.random.normal(32, 7, size=n_rows), 10, None), 1),
        "rating": np.round(np.random.uniform(2.0, 5.0, size=n_rows), 1),
        "discount_pct": np.round(np.random.uniform(0, 25, size=n_rows), 1),
    })

    # Introduce 4% nulls in two numeric columns to demonstrate cleaning at startup
    for col in ["delivery_time_mins", "rating"]:
        idx = np.random.choice(df.index, size=int(0.04 * n_rows), replace=False)
        df.loc[idx, col] = np.nan

    # Check and fill any null values in numeric columns
    numeric_cols = df.select_dtypes(include=[np.number]).columns
    null_total = df[numeric_cols].isnull().sum().sum()
    if null_total > 0:
        for col in numeric_cols:
            if df[col].isnull().any():
                df[col] = df[col].fillna(df[col].median())
        print(f"[Startup] Detected and imputed {null_total} null values using column medians.\n")

    return df


# Option 1: Primary module -> NumPy statistical functions
def option_summary_statistics(df):
    print("\n--- (1) Summary Statistics (NumPy) ---")
    numeric_cols = df.select_dtypes(include=[np.number]).columns
    print(f"{'Column':<20} {'Mean':>10} {'Median':>10} {'Std Dev':>10} {'Min':>10} {'Max':>10}")
    print("-" * 72)
    for col in numeric_cols:
        arr = df[col].to_numpy()
        print(
            f"{col:<20} {np.mean(arr):>10.2f} {np.median(arr):>10.2f} "
            f"{np.std(arr):>10.2f} {np.min(arr):>10.2f} {np.max(arr):>10.2f}"
        )


# Option 2: Primary module -> Matplotlib subplots
def option_distribution_analysis(df):
    print("\n--- (2) Distribution Analysis (Matplotlib Subplots) ---")
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))
    fig.suptitle("Order Value & Delivery Time Distributions", fontsize=13, fontweight="bold")

    axes[0].hist(df["order_value"], bins=20, color="#2a9d8f", edgecolor="black", alpha=0.8)
    axes[0].set_title("Order Value Distribution")
    axes[0].set_xlabel("Order Value (Rs)")
    axes[0].set_ylabel("Frequency")

    axes[1].hist(df["delivery_time_mins"], bins=20, color="#e76f51", edgecolor="black", alpha=0.8)
    axes[1].set_title("Delivery Time Distribution")
    axes[1].set_xlabel("Delivery Time (mins)")
    axes[1].set_ylabel("Frequency")

    plt.tight_layout(rect=[0, 0, 1, 0.93])
    filename = "capstone_distribution_analysis.png"
    plt.savefig(filename, dpi=150)
    plt.close()
    print(f"Chart saved successfully as '{filename}' (DPI=150).")


# Option 3: Primary module -> Seaborn heatmap
def option_correlation_heatmap(df):
    print("\n--- (3) Correlation Heatmap (Seaborn) ---")
    corr = df.select_dtypes(include=[np.number]).corr(method="pearson")
    plt.figure(figsize=(8, 6))
    sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1, linewidths=0.5)
    plt.title("Pearson Correlation Heatmap - Food Delivery Metrics")
    plt.tight_layout()
    filename = "capstone_correlation_heatmap.png"
    plt.savefig(filename, dpi=150)
    plt.close()
    print(f"Chart saved successfully as '{filename}' (DPI=150).")


# Option 4: Primary module -> Pandas groupby aggregation
def option_restaurant_performance(df):
    print("\n--- (4) Restaurant Performance Report (Pandas GroupBy) ---")
    report = (
        df.groupby("restaurant_name")
        .agg(
            total_orders=("order_value", "count"),
            avg_order_value=("order_value", "mean"),
            avg_delivery_time=("delivery_time_mins", "mean"),
            avg_rating=("rating", "mean"),
        )
        .sort_values(by="avg_rating", ascending=False)
        .round(2)
    )
    print(report.to_string())


def print_exit_summary_report(df):
    print("\n" + "=" * 60)
    print("FINAL EDA SUMMARY REPORT")
    print("=" * 60)

    # 1. Top 3 restaurants by mean rating
    top3 = (
        df.groupby("restaurant_name")["rating"]
        .mean()
        .sort_values(ascending=False)
        .head(3)
    )
    print("\n1. Top 3 Restaurants by Mean Rating:")
    for rank, (name, score) in enumerate(top3.items(), start=1):
        print(f"   {rank}. {name}: {score:.2f}")

    # 2. Numeric column pair with highest absolute Pearson correlation
    corr = df.select_dtypes(include=[np.number]).corr(method="pearson").abs()
    np.fill_diagonal(corr.values, 0)
    max_pair = corr.stack().idxmax()
    actual_corr = df[max_pair[0]].corr(df[max_pair[1]])
    print(
        f"\n2. Highest Absolute Pearson Correlation Pair:\n"
        f"   {max_pair[0]} & {max_pair[1]} (r = {actual_corr:.4f})"
    )

    # 3. Overall mean and std of delivery time
    dt_mean = np.mean(df["delivery_time_mins"])
    dt_std = np.std(df["delivery_time_mins"])
    print(
        f"\n3. Overall Delivery Time Statistics:\n"
        f"   Mean = {dt_mean:.2f} mins | Std Dev = {dt_std:.2f} mins"
    )
    print("=" * 60)


def main():
    df = generate_and_clean_dataset(n_rows=250)

    while True:
        print("\n=== Food Delivery Analytics Console ===")
        print("1. Summary Statistics")
        print("2. Distribution Analysis")
        print("3. Correlation Heatmap")
        print("4. Restaurant Performance Report")
        print("5. Exit")

        choice = input("Select an option (1-5): ").strip()

        if choice == "1":
            option_summary_statistics(df)
        elif choice == "2":
            option_distribution_analysis(df)
        elif choice == "3":
            option_correlation_heatmap(df)
        elif choice == "4":
            option_restaurant_performance(df)
        elif choice == "5":
            print_exit_summary_report(df)
            break
        else:
            print("Invalid selection. Please enter a number from 1 to 5.")


if __name__ == "__main__":
    main()

g.fig.suptitle("Food Delivery Numeric Features by Cuisine Type", y=1.02)

# Fix 2: Pass numeric_only=True to df.corr() so string column 'cuisine_type' doesn't raise ValueError

4. EXPLANATION OF CHANGES (3-4 LINE NOTE):
------------------------------------------
In Pandas 2.x, calling df.corr() directly on a DataFrame containing the string
column 'cuisine_type' raises a ValueError, so I added numeric_only=True to
compute correlations strictly on numeric columns. I also added plt.close() after
saving the pairplot and initialized a new plt.figure() for the heatmap so the
two plots do not overlap in memory. Finally, I added plt.tight_layout() and
dpi=150 / bbox_inches="tight" to prevent axis labels from getting clipped in the
exported PNGs.
